# Rationale — sofa Desk options (Forge lock)

## Killed (prior mocks)

- **Crowded Mesa** — Factory + embedded Agora (progress, pick list, Separar) + long queue on one screen. That was admin density, not sofa calm. Progress and separation live on the Run page after tap.

- **Inventing a new owner Run** — Cards, grids, or “wave detail dashboards” that are not the approved **Waze map + bottom game HUD** (qty / next / Speak). Owner variants only add richness: full route, peek/back, Compartilhar, more context — same forward skeleton as `/r`.

- **Ghost waves and contradictory factory** — Still excluded. Every desk shows what’s missing for the next auto-wave (or a clear enable path). Lists are real waves only; #1042 stays tied to **gerada no setup**.

- **Employee `/r` in scope** — Not mocked; one-line contrast on owner pages only (forward-only, no map).

- **Single `/desk` polish** — Replaced by **six** openable personalities so Chair can compare IA without re-reading one toggled file.
