## Killed (prior mocks)

- **Invented Owner Run chrome** — White bottom sheet, Speak card, Separar as the primary game button, warm beige “Waze × Link” skin, mint accents. That was a different product. Owner-wave is now locked to the **approved Pisoly Run PNGs** (shots 2–11): full-bleed cool gray-blue aisle paper, thick indigo `#635bff` path (solid = done/current leg, dashed = upcoming), green filled current node, `N de 18` top-right, huge qty + location + `depois X-YY` bottom-left, dark circular **Feito** bottom-right.

- **Crowded Mesa** — Factory + embedded Agora (progress, pick list, Separar) + long queue on one screen. Progress and the game live on the Run after tap.

- **Ghost waves and contradictory factory** — Still excluded. Every desk shows what’s missing for the next auto-wave. Lists are real waves only; #1042 stays tied to **gerada no setup**.

- **Employee `/r` in scope** — Not mocked. Strict Run is forward-only. Owner uses the same visual grammar and may peek / go back; Separar and share stay optional secondary.

- **Single `/desk` polish** — Replaced by **six** openable personalities so Chair can compare IA without re-reading one toggled file.
